# 桌面录音音源控制：实现与验证记录

日期：2026-10-22。

桌面端核心能力已实现。本文区分已开发、已验证和仍需配合的部分，不代表全部 PRD 验收项或发布验收已经完成。

## 已实现

- 主录音页、字幕模式、悬浮窗复用电脑与麦克风图标控件。关闭时图标中心加斜线，静音时保留开启图标；设备缺失另有异常标记和原因。支持键盘操作、悬停说明和读屏状态。
- 录前选择沿用现有启动偏好；录音中切换只影响本次会话。独立开关经过原生采集确认后更新，不以界面点击代替采集成功。
- macOS、Windows 启动时区分设备可用性和授权。双路只保留其中可用且已选择的来源；明确选择单路时不扩大采集范围。仅电脑声音不请求麦克风权限，Core Audio 麦克风单录不要求系统音频授权。
- macOS 通过控制管道、Windows 通过采集引擎切换来源；关闭会停止对应设备通路及写入。原始轨、处理轨和识别帧均受来源边界约束；旧回调与旧版本帧不能重新激活关闭来源。
- 同一会话保留计时和已有内容；最后一路通过暂停操作停止收音。设备丢失可保留另一已选来源，唯一来源失效则暂停。用户关闭的来源不会因设备恢复而自动开启。
- 主录音页、录音条和悬浮窗波形读取有效录音信号。macOS 总波形使用实际回放混音的峰值；单路不继续采集另一来源作为回声参考，双路沿用已有自动回声处理，并在有电脑声音且回声处理降级时即时提示；悬浮窗展开状态也可查看。
- 录音保存来源生效区间，空音轨不再作为可试听来源展示。麦克风长时间关闭后重新开启，以稀疏静音保持文件时间轴，不分配整段静音内存，也不向识别服务补发关闭期间的静音历史。
- 本地回放使用原生峰值缓存，综合所有声道；切换文件或音轨立即清除旧波形。窄播放器会覆盖完整录音时间轴，加载及失败状态可见并支持重试。
- macOS 采集时累计混音峰值，长录音停录时直接建立缓存；缺缓存或导入 WAV 则采用有界内存流式提取。压缩音频继续使用原有浏览器解码兼容路径。
- 上传成功后，本机保留与上传对象路径绑定的峰值快照。同一台电脑打开该云端音频版本时可以复用；云端对象替换或本地后续编辑不能借用旧版本波形。
- 新增文案覆盖简体中文、繁体中文、英文、日文、韩文。

## 尚未完成的验收与依赖

1. **真机验收**：macOS / Windows 的权限切换、USB / 蓝牙设备热插拔、双讲与外放回声质量、驱动异常，以及两小时连续录音和响应时间，需要在对应设备实测。交叉编译与合成测试不能替代这些结果。
2. **云端跨设备元数据同步**：来源区间、峰值缓存及已上传版本快照目前保留在本机。现有前端上传合同没有携带这些元数据，本次没有修改外部后端；另一台电脑恢复它们仍需后端字段或伴随文件协议。未在本机生成缓存的云端长音频仍走既有解码限制，并明确显示波形不可用状态。

## 体验与交付

正常使用仓库的 `pnpm dev:desktop` 启动流程即可重建采集 sidecar 并使用新界面。直接复用旧采集二进制不能验证新增控制合同。

本次保留工作区已有的知识图谱、Wiki、聊天等其他改动；没有提交、发布或替换已安装的桌面应用。
