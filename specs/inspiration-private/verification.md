# 灵感私有存储实施与验收记录

本次提交范围包含桌面实现及 `lynclaw/services/lynse-memory` 后端代码。
代码已经接入现有保存、列表、详情、附件和同步入口；没有部署到线上，也没有发布安装包。
当前生产加密开关默认关闭，下面的外部验收项不能用本地测试替代。

## 已实现

- 笔记列表和内容面板移除“准备会前回顾”入口。
- 输入框的锁图标紧邻保存按钮左侧；卡片锁用于持久化切换加密状态。
- 首次使用设置并确认独立加密密码，要求至少 12 个字符，并确认保存恢复码。
  当前账号在当前设备共用此密码。登录密码重置不提供内容恢复能力。
- Rust 原生保险库、独立系统钥匙串、Argon2id/HKDF、XChaCha20-Poly1305、
  Secretstream 附件、恢复码、可信设备配对、撤销与密钥轮换。
- `Memory/<account_scope>/Inspirations/<record_uuid>/<opaque_uuid>.bin`，
  账号分区索引、可恢复操作队列、原生临时预览能力和用户指定位置导出。
- 记录及附件 v2 协议，服务端身份范围、强制 RLS、复合外键、CAS、幂等回执、
  转换冻结、分块摘要验证、删除墓碑和退役对象清理。
- 禁止受保护内容进入转写、AI 来源、召回、Wiki、MCP、自动 Markdown 镜像和
  问题报告截图。解锁不改变 AI 排除；取消加密仍关闭 AI。
- 账号切换和锁定清理正文查询、草稿、预览和对话框；旧 Token 不能继续新账号的同步。
- 历史全局闪记显式认领。服务端未配置审定旧身份范围时，不允许旧接口跨环境取数，
  也不将旧来源自动分配到当前账号。
- 普通转加密明确显示历史副本清理尚未验证，不承诺回收已经导出的明文。
- 翻译审计支持模块导入和隐私命名空间，同时补齐审计发现的已有录音模式错误文案。
