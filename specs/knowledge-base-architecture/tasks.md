# 实施与验收

2026-11-15 · [需求](requirements.md) · [架构设计](design.md)

## 已接通的路径

- 来源提交后由 SQLite FTS5 提供原文搜索。内容和位置未变的段落保留原定位。
- Wiki 按来源和受限分块更新。已完成的目录归组、抽取和编译缓存使用内容及处理协议标识。人工审核页的自动更新进入候选。
- 桌面搜索、助手上下文、知识简报和本地 MCP 调用同一检索入口。Web 的账号知识搜索融合关键词和段落向量。后台任务为已授权资料建立向量，模型暂不可用时继续返回关键词结果。
- 新版共享专题使用条件写入和删除记录。桌面可比较冲突版本、编辑并确认合并稿，原版本进入历史。可以确定互不重叠的正文改动时提供合并建议。提交时重新核对本机与云端版本以及当前来源权限。
- 直连模型的未知执行结果保留回执或等待显式重试。明确限流与提交前连接失败按退避重试。

| 场景 | 验收 |
| --- | --- |
| 重放、重启、换模型 | 已完成且引用有效的资料应有 0 次新增生成、0 个正文新版本。现有调度、内容标识和缓存测试覆盖此路径。 |

| 人工编辑与撤销 | 覆盖自动更新进入候选、元数据变化重绑引文、旧授权重放被阻断及已删除专题不能被覆盖。 |
| 双设备 | 本地测试覆盖新版页面与小节的收养、引用重绑和云端条件发布。两台真实设备的断网重连及冲突操作待验。 |
| 检索、引用与问答 | 已验证跨账号隔离及撤权。需用同一批标注资料对照 Lynse 原版和 WeKnora，测 Recall@10、正确率、引用准确率及搜索延迟。 |

## 本地验证记录

- Rust 全量回归通过 552 项，6 项默认忽略。其中 Wiki 和图谱的 2 项本机模拟测试另行通过。
- 前端类型检查、1084 项测试、桌面渲染层和 Web 生产构建通过。1 项真实后端测试默认跳过。
- Lynclaw 知识库、来源授权、同步、API 契约和会议发布回归通过 138 项，1 项跳过。
- 本机合成数据串联 Lynclaw HTTP、Rust 校验与持久化和 Chromium 桌面渲染，Wiki、图谱及纪要引文可读。
- 混合检索与冲突合并补充验证通过。隔离 PostgreSQL 的 36 项回归覆盖段落向量复用、版本与租户隔离、网关及后台任务。桌面的 5 项同步回归和冲突界面测试覆盖合并建议、双方历史及版本变化后保留草稿。桌面渲染层与 Web 生产构建通过。
- 更广的 PostgreSQL 套件中，数据库备份和迁移计数两项在未修改的基线版本上同样失败。本地测试使用合成向量。真实 embedding 服务和双设备生产同步待发布后验证。
